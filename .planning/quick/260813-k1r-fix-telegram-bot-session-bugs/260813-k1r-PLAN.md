# Plan: Fix 5 bugs in Telegram bot files

## Context

Hai bot Telegram (Manager + KTV) có 5 bug cần fix:

1. **BotSession conflict** — cả 2 bot dùng chung bảng `bot_sessions` với `chat_id` làm PK. Nếu cùng 1 người dùng cả 2 bot thì session bị ghi đè.
2. **Stale `/baodien` message** — `_cmd_huy` trong manager bot vẫn nói "Gõ /baodien" nhưng manager đã bỏ lệnh này.
3. **KTV webhook thiếu secret token validation** — manager bot validate nhưng KTV bot không.
4. **Test mock signature sai** — mock `_notify_manager` chỉ có 3 params nhưng function thực có 4.
5. **Stale docstring** — docstring ở manager bot vẫn mô tả flow cũ (gửi ảnh, /baodien).

## Tasks

### Task 1: Fix BotSession model — thêm `bot_type` composite PK

**Files:** `backend/app/models/bot_session.py`

Thêm `bot_type: Mapped[str]` là phần của composite PK `(chat_id, bot_type)`.
Default value là `"manager"` để backward compat.

### Task 2: Fix manager bot — _get_session + _cmd_huy + docstring

**Files:** `backend/app/api/v1/telegram_bot.py`

- Cập nhật `_get_session` để filter và tạo session với `bot_type="manager"`
- Fix `_cmd_huy`: thay "Gõ /baodien để bắt đầu lại." → "Gõ /duyet để xem chỉ số mới."
- Cập nhật docstring cho đúng flow hiện tại

### Task 3: Fix KTV bot — _get_ktv_session + webhook secret validation

**Files:** `backend/app/api/v1/telegram_bot_ktv.py`, `backend/app/core/config.py`

- Cập nhật `_get_ktv_session` để filter và tạo session với `bot_type="ktv"`
- Thêm `TELEGRAM_KTV_WEBHOOK_SECRET: str = ""` vào Settings
- Thêm secret token validation vào KTV webhook endpoint

### Task 4: Fix test mock signature

**Files:** `backend/tests/test_telegram_ktv_bot.py`

- Fix mock `_notify_manager` từ 3 params → 4 params (thêm `building_name=""`)

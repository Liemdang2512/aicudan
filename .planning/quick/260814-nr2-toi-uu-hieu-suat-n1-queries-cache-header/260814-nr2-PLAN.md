    3. Query `MeterReading` previous (N queries)

    Fix — TRƯỚC vòng lặp `for room in rooms:`, thêm 3 batch pre-fetch:

    1. Pre-fetch existing invoices:
       ```python
       existing_invoices_res = await db.execute(
           select(Invoice.room_id, Invoice.id).where(
               Invoice.room_id.in_([r.id for r in rooms]),
               Invoice.invoice_month == body.invoice_month,
           )
       )
       existing_invoice_map = {row.room_id: row.id for row in existing_invoices_res}
       ```

    2. Pre-fetch current readings (approved, trong tháng, latest per room):
       SQLite không có DISTINCT ON, dùng subquery hoặc fetch all rồi deduplicate trong Python.
       Approach an toàn: fetch tất cả approved readings trong tháng cho các rooms, sort by (room_id, reading_date desc, id desc), deduplicate giữ first per room_id.
       ```python
       current_readings_res = await db.execute(
           select(MeterReading).where(
               MeterReading.room_id.in_([r.id for r in rooms]),
               MeterReading.status == "approved",
               MeterReading.reading_date >= month_start,
               MeterReading.reading_date < next_month,
           ).order_by(MeterReading.reading_date.desc(), MeterReading.id.desc())
       )
       current_reading_map: dict[int, MeterReading] = {}
       for mr in current_readings_res.scalars().all():
           if mr.room_id not in current_reading_map:
               current_reading_map[mr.room_id] = mr
       ```

    3. Pre-fetch previous readings (approved, trước month_start, latest per room):
       Chỉ cần cho rooms có current reading. Dùng cùng pattern deduplicate.
       ```python
       rooms_with_current = [rid for rid in current_reading_map]
       prev_readings_res = await db.execute(
           select(MeterReading).where(
               MeterReading.room_id.in_(rooms_with_current),
               MeterReading.status == "approved",
               MeterReading.reading_date < month_start,
           ).order_by(MeterReading.reading_date.desc(), MeterReading.id.desc())
       )
       prev_reading_map: dict[int, MeterReading] = {}
       for mr in prev_readings_res.scalars().all():
           if mr.room_id not in prev_reading_map:
               prev_reading_map[mr.room_id] = mr
       ```

    Trong vòng lặp: thay `await db.execute(...)` bằng lookup từ maps. Giữ nguyên logic tính toán consumption, calculate_invoice, error handling, room_results.
